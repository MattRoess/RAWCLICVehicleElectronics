## 3. What changed today

### 3.1 The composition band was not Monte Carlo — fixed

The figures' cross-domain band came from `_lognormal_from_band()`: it took each
domain's mean/P2.5/P97.5, **invented a lognormal** matching those three numbers,
and summed the four domains as independent. The models' own draws never entered.

Now: `tools/mc_composition.py` pushes **one simulated car through all four
models** with shared drivers and sums the four masses **per draw**. Validations
C1–C4 over 153 (segment, year) cells; C4 shows `sum(domain means) == total mean`
to **8.06e-16**, which is the proof the summation is genuinely per-draw.

Full record: `12_JOINT_MC_DESIGN.md`.

### 3.2 Defects found and fixed along the way

| | what was wrong |
|---|---|
| Sensors, PCB | never drew a hardware tier — every car got the fleet-average presence. Now a discrete per-vehicle draw |
| Motor elements | `TotalMass` summed as if it were an element → every stream counted **twice** |
| Motor elements | Aluminium and Plastic dropped entirely — **17.7% of motor mass** |
| Motor elements | resampled a 50-bin histogram instead of using the model's own draws, and broke the pairing between materials of one motor |
| NdFeB | fractions did not sum to 1 (0.982–1.113) — no balance element |
| `_shift_shares` | duplicated in `BevWiring` and `drivers` |

Motor composition now reconciles with `ElectricMotorMC` to **0.008–0.022%**,
from **1.57–1.79×** at the start of the day.

### 3.3 Magnets are ferrite, not NdFeB

Auxiliary-motor magnets are strontium ferrite (Y30/Y35/Y40, equal thirds, no
barium), per your own investigation. **Rare earths went to zero**: EF was
carrying 1.66 kg of neodymium and 0.38 kg of dysprosium per vehicle.

Recorded in the code and worth revisiting: `10_`'s ferrite rows give Sr 15–20%
against SrFe₁₂O₁₉ stoichiometry of **8.3%** — roughly double. Matters if you
quote strontium demand.

### 3.4 Structure

- **Folders numbered `01_`–`07_`** in run order. Files are not numbered because
  a Python file starting with a digit cannot be imported, and four of these are
  imported as libraries.
- **`ElectricMotorElementMC` is table-driven.** One `Stream` entry per material
  holds sheet, elements, grades, weights, balance element, mass column, globs and
  output folder. Four loaders → one; four samplers → one; 1,491 → 1,249 lines.
  **Verified byte-identical.** Changing a material is now a data edit.
- **Output folders name the role, not the chemistry** — `MagnetElemental`, so a
  chemistry change cannot orphan a folder again.

### 3.5 Which assumptions actually matter

`tools/driver_sensitivity.py` freezes each driver and reports what the total band
loses. Of a 41–57% band:

| driver | AB 2040 | CD 2040 | EF 2040 |
|---|---|---|---|
| zonal architecture | **15.8** | **10.7** | 2.9 |
| 400 V → 800 V | 4.2 | 1.1 | 1.5 |
| post-2040 scenario | 1.3 | 1.2 | 1.9 |
| ADAS hardware tier | 0.2 | 0.4 | −0.0 |
| lidar / China lag | 0.0 | −0.0 | 0.0 |

**Architecture is the only driver that really moves the total.** The ADAS tier
and lidar sit below Monte Carlo noise. Run this before arguing about any
assumption.

## 5. For the stock-and-flow model

| file | what |
|---|---|
| `Data/30_BEV_electronics_composition.csv` | grams per vehicle by year, segment, domain, component type, element — **the means** |
| `Composition/csv/joint_mc_stats.csv` | mean, P2.5, median, mode, P97.5 — **the band** |
| `Composition/draws/<seg>_<series>.npy` | raw per-draw arrays, for pairing draw-for-draw with your own vehicle counts |

**The rule: means add, percentiles do not.** Never sum `P2_5_g` / `P97_5_g`
across rows — at CD 2040 that gives 47.8 kg against a true band of 35.9 kg,
**33% too wide**. Sum means freely; take the band from `joint_mc_stats.csv`; for
any other aggregation multiply the **draws**.

`30_` is **per vehicle**. Across a fleet the average is far more certain than one
car, so per-vehicle uncertainty does not scale up unchanged.

**`30_` is no longer in git.** Hand it to the stock-and-flow model directly, or
regenerate it with `tools/build_composition.py`.
